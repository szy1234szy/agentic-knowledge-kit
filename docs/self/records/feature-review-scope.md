# FEAT-KIT-REVIEW-SCOPE 按资产类型复核

## 需求与设计

工程资料增多后，维护者有时只想复核运维或架构。为 review 添加 --kind，沿用索引中的资产类型。--kind 单独使用时复核该类型的现行资产，与 --all 联用时只读取该类型的 Markdown 正文进行查重。

继续保护 [INV-KIT-001](invariants.md) 的只读审查和资料边界。以同一个自用索引验证功能开发前后的检索和影响分析。

## 验收

| 验收项 | 状态 |
| --- | --- |
| 指定类型后仅复核该类型的现行资产 | 已验证。自用索引的架构审计仅返回 ARC-KIT-001 |
| 按类型做正文查重时跳过无关类型 | 已验证。旧编码的其他类型不会产生读取警告 |
| 原有核心筛选及显式 ID 查询继续可用 | 已验证。保留原测试并复跑 |

交付后运行 impact，复核了架构说明、能力边界、审计不变量和故障记录。实现与验证见 [实测记录](verification.md)。
