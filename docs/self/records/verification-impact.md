# EVID-KIT-IMPACT-001 证据影响反查验证

v0.12 使用自用索引从安装测试路径查影响，只列出一条共用证据和审计功能计划。这个结果暴露了两处问题：架构或约束使用的证据反查能力不足，安装、审计和故障修复共用证据也会把无关计划带进结果。

v0.13 将安装、已有审计功能、编码故障和本轮变更的证据分别登记。复跑安装测试路径，输出安装、质量和安装约束相关记录。复跑审计测试路径，仍能找到审计功能和编码故障。证据记录通过严格校验。
