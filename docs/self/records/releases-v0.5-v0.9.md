# v0.5 至 v0.9 版本记录

| 版本 | 发现的问题 | 修复和验证 |
| --- | --- | --- |
| v0.5 | 中间功能仍标为已验证时，下游计划看不到重新打开的上游依赖 | 遍历直接和间接前置，验证共享依赖只报告一次 |
| v0.6 | 工程文档迁移后，索引校验无法定位正文里的失效链接 | 新增 `links`，验证文件位置、行号和相对路径，并跳过代码示例和外部网址 |
| v0.7 | 记录文档被删除或移动后，影响查询因文件缺失退出，无法找回旧索引 | 查询保留警告并返回候选，校验继续拒绝失效记录文件 |
| v0.8 | 安装在复制部分文件后才发现路径冲突，重复升级会重写相同内容 | 写入前预检整批目标，增加 `--dry-run`，逐文件替换并跳过相同内容 |
| v0.9 | 已验证证据中的类名限定方法和行范围可能未经检查就通过 | 校验 Python 限定符号及文件行范围，增加同名方法与越界回归 |

各版本保留旧索引格式。校验新支持的锚点时，如发现旧记录失效，应按实际文件修正引用。安装器能提前检查可见的路径冲突，逐文件写入仍可能受权限或运行中的磁盘错误影响。工程文档链接检查覆盖常见 Markdown 本地路径，其他标记语法和业务证据继续由维护者核实。
