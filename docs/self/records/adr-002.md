# ADR-KIT-002 以本地路径和显式关系定位项目知识

## 当前决策

沿用项目根目录的 Markdown、JSON 索引、Python 标准库和可选 Git 基线。用路径及范围匹配候选，沿显式关系查找决策、约束和证据。本版把现行机制及其取舍记录为维护决策，早期完整的备选方案评审记录未登记。

## 依据与代价

- 同一输入下，工具可以展示候选来自直接文件、范围或登记关系。维护者能在 Git 中看到索引差异并修正引用。
- 继续复用 Markdown 与 CLI 入口，保留安装后可离线完成结构校验和路径检索的能力。
- 仅查全文容易找到提及同一术语的材料，显式关系更便于说明为什么某条资料关联本次改动。两者可以互相补充。
- 语义检索可在命名差异较大时帮助发现资料；现阶段项目缺少量化对照，先由代码搜索补足未登记关系，并保留已验证的路径和关系工作流。
- 结构校验限制在可证实的文件和索引事实。项目测试与人工评审承担业务契约和历史决策理由的核实。

## 实现与验证

实现见 [知识工具](../../../scripts/knowledge.py)。典型验证见 [自用索引入口测试](../../../scripts/test_self_knowledge.py) 与 [证据反查实测](verification-impact.md)。如果后续加入其他检索机制，仍应能回溯到仓库路径、记录和证据，并用真实任务对比召回与误报。
