# ADR-KIT-001 自用资料与目标项目骨架分开

状态为已接受。套件既要管理自身资料，也要能安装到业务仓库。安装器会复制 docs/knowledge，因此将自身记录放入该目录，需要长期维护一份排除清单。

本次采用 docs/self 和备用索引。自用命令需显式指定 --registry docs/self/registry.json。发布包保留自身资料供查阅，默认安装的索引用于目标项目的事实。

v0.18 复验了两个安装入口。新建目标通过校验时索引为空。已有目标从 v0.17 升级后，一条预先登记的记录、项目概览、`AGENTS.md` 和 CI 配置保持原内容。操作和验收方式见 [工程手册](../engineering-guide.md#安装与升级)。
