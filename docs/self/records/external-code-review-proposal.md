# RULE-KIT-EXTERNAL-001 代码变更验收记录

状态为提案，待维护者确认项目化条款。来源是原知识库中的《AI 代码修改与复盘规范》，章节「修改完成后的交付」与「输出原则」。来源版本暂未提供。

## 适用范围

套件工具、安装脚本和相关回归测试发生行为变更的任务。关键修改可用 Git 差异核对。当前独立发行目录缺少 Git 历史时，注明对比的文件或基线发布包。

## 拟采纳的条款

在交付记录中说明变更前后的可观察行为、方案理由和影响范围。分列实测、未执行的检查和剩余风险。相同行为的文档只更新一处，由功能计划或索引链接。原笔记中的学习提问可在用户需要复盘时按需使用。

## 验证与维护

评审人对照实际改动、测试命令和结果复核。可参考 [工程手册](../engineering-guide.md#开发与知识同步) 与 [质量验证](../engineering-guide.md#校验与发布)。若来源条款和项目 ADR 冲突，先记录影响范围和待决事项。确认采纳后，再在索引中变更状态。
